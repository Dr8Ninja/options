# Research records

`inventory/` is the immutable-source extraction checked by inventory_sources.py. `evidence/` contains access observations, source hashes and claim-review scope; HTTP retrieval does not establish content review. `registers/` contains coverage, checklist, questions, claims, gaps and historical cases. `design/` contains compact authored editorial inputs used to generate canonical exports and module/project dossiers.

`search-log-p01.json` preserves raw search/open arguments; durable canonical URLs and section scopes are in resources/claims/evidence. Temporary third-party full-text caches are outside the repository. No paid book or licensed market dataset is distributed here.

`validation-p01.json` is the deterministic structural/reference/graph/round-trip result for its explicit as-of date. `numerical-checks-p01.json` checks selected original reference examples; it is not an empirical strategy replication. Human-readable findings and review records are under docs/research.

`final-audit-p01.json` verifies all five archived files against the source manifest and checks local Markdown link targets. It does not certify external link availability or heading anchors. Run `python3 scripts/audit_p01_package.py` from the repository root to repeat it.
