## Refinements based on the actual inventory

1. The original build prompt assumes research is complete. P01 must demonstrate its gate before P02 starts; today's early evidence is insufficient.
2. The original 1,019 topics are scope records. P01 designs the canonical learning system; P17 separately authors and verifies release lessons. Initial release scope cannot erase promised professional expansion.
3. The existing catalog omits capstones and other Markdown guidance. P01 reconciles them; P09 proves they survive import.
4. Inherited module-resource links are not exact topic citations. P01 makes explicit assignments and records review scope.
5. Content import moves before feature APIs/UI so implementation uses real data; test/secure implementation accompanies each stage.
6. Database and admin editing need an explicit shared content authority. P03 resolves it; P09/P16 test conflicts rather than overwriting edits.
7. Self-completion, assessed mastery and publication readiness are separate states. P04/P14/P15/P17 implement that distinction.
8. Required practice remains educational/simulated. Optional live trading is not a graduation requirement or an authorization to place trades.
9. Deployment preparation and actual publishing are separate. P22 needs a concrete requested target; no automatic publishing follows writing these prompts.
10. The three review passes are distinct methods/lenses, not a false claim that independent people or agents reviewed the curriculum.
