# Mathematics track

“Mandatory” means mandatory for the named financial competency, not for every learner. The module codes in this table resolve the mathematics tags in every dossier. Each stage begins with intuition, a worked financial calculation, a numerical check and a failure case. Paper/calculator routes are available through core probability and cash-flow work.

| Code and classification | Concepts and required financial use | Sequence, diagnostic and practice | Selected readings / effort |
|---|---|---|---|
| A — mandatory for all | Algebra, functions, logs, units, percentages, compounding, discounting; M01/M21–M29/M45 | Units → cash ledger → payoff piecewise functions → present value. Diagnose 20% drawdown recovery. Explain why log returns add while arithmetic returns compound. | M01/B02; MIT Finance Theory I selected present-value material;6–15h beyond module work if bridge needed. |
| S — mandatory for research and risk; basic part mandatory for retail | Random variables, conditional probability, distributions, moments, covariance/correlation, expectation; M10/M11/M35/M45/M46/M55 | Skewed payoff expectation → conditional events → estimation uncertainty → regression/inference → dependent samples and block bootstrap. Simulate counterexamples to independence. | MIT18.05 selected probability, expectation, intervals and tests;25–60h. |
| C — mandatory for analytic Greeks/pricing; useful for discretionary intuition | Limits, derivatives, partials, chain rule, integrals, Taylor approximation, elementary differential equations; M13/M29–M34 | Finite slope → partial derivative → second-order P&L → PDE balance. | L — useful for basic portfolio work; mandatory for calibration/ML | Vectors/matrices, covariance PSD, eigenvalues, least squares, conditioning, constrained optimization; M08/M13/M37/M48/M57 | Two-asset covariance → exposure vector → least squares → constrained calibration. Bayesian reasoning about uncertainty is introduced earlier in M11; formal posterior computation is optional depth. | Read a specific primary paper only after a concrete use case; open-ended effort. |

For regression, distinguish explanatory coefficients from tradable forecasts; residual diagnostics and a fixed prediction timestamp are required. For bootstrap, preserve relevant dependence and report the block-length sensitivity. For Bayesian work, show prior and likelihood sensitivity rather than treating a posterior as objective certainty. For Monte Carlo, fix seeds for reproducibility but vary seeds to assess uncertainty. For optimization, test multiple starts and inspect constraints rather than equating solver success with identification.

Short derivation check: if dS/S = μdt + σdW, the Itô correction gives dlogS = (μ − σ²/2)dt + σdW. With μ=.08 and σ=.2 the log drift is .06. This does not turn physical μ into the risk-neutral drift; the pricing measure follows replication/market assumptions. M14 asks for both the derivation and a simulation check.
