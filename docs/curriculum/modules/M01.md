# M01 — Financial arithmetic and economic purpose

Status: learning design; topic lessons remain P17. Slug: `financial-arithmetic-and-economic-purpose`. Beginner; 14–36 hours. Tags: foundations, financial-and-market-foundations.

Reconcile units, cash, equity and compounded returns before accepting any payoff claim.

Hard prerequisites: none. Recommended preparation: none. Optional enrichment: none. Diagnostic: Why is notional different from cash required and worst loss? Bridge: B01.

Estimation basis: Editorial estimate for selected readings, scope navigation, one worked calculation, one transfer variant, practical work and remediation; 45–90 minutes per ordinary scope topic plus 2–8 practical hours, longer for specialist derivation. Projects budgeted separately. Not measured learner time.

Objectives:

- Reconcile units, cash, equity and compounded returns before accepting any payoff claim.
- Solve and explain: Lose 20% from 100 then gain 20%: equity 96; recovery from 80 needs 25%.
- Audit the failure mode: Adding sequential returns; treating premium as notional.

Mathematics: A (codes in MATH_ROADMAP). Programming: None for core explanations; optional Python for replication.

Reading: R01:II; R16:present value lectures. Resource verification limits control use; a TOC assignment is a candidate, not a reviewed chapter. All learners can complete the synthetic numerical case without buying a book.

Ordered scope:

- M01.01 — Units and signs: currency, points, ticks, percentages, basis points, contracts, multipliers; dimensional checks
- M01.02 — Percent change: simple returns, drawdowns, asymmetric recovery arithmetic
- M01.03 — Compounding: geometric growth, arithmetic averages, geometric averages, volatility drag
- M01.04 — Time value of money: present value, future value, discount factors, continuous compounding
- M01.05 — Real and nominal returns: inflation, purchasing power, currency conversion
- M01.06 — Profit and loss: realized, unrealized, gross, net, mark-to-market, cash flow versus income
- M01.07 — Capital and solvency: account equity, available cash, collateral, liabilities, liquidation value
- M01.08 — Leverage: gross notional, net notional, effective leverage, embedded optionality
- M01.09 — Trading purposes: investment, speculation, hedging, insurance, liquidity provision, arbitrage
- M01.10 — Opportunity cost: passive alternatives, cash yield, time, data and infrastructure expense
- M01.11 — Risk capital: essential living funds, capital at risk, withdrawals, finite trading runway
- M01.12 — Market efficiency: information sets, weak/semi-strong/strong forms, limits to arbitrage
- M01.13 — Risk premium versus alpha: compensation for bearing risk versus incremental skill
- M01.14 — Decision objectives: survival, learning, hedging effectiveness, growth, capacity, constraints

Teaching brief for module delivery: begin with the checkpoint dilemma, elicit the learner's units and obligations, work the numerical case, then use the practical assignment to challenge the main assumption. Ask for a counterexample before extending the scope. This is a module delivery plan, not a topic lesson.

Common mistakes:

- Adding sequential returns; treating premium as notional.
- Accepting a result without its units, assumptions or source date.
