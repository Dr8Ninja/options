# M09 — Event taxonomy and information processing

Status: learning design; topic lessons remain P17. Slug: `event-taxonomy-and-information-processing`. Intermediate; 12–32 hours. Tags: event-trading, fundamentals-macro-and-events.

Construct a timestamped event calendar and precommit scenarios.

Hard prerequisites: C-M21, C-M10. Recommended preparation: C-M03, C-M06, C-M07. Optional enrichment: none. Diagnostic: Why is an earnings gap different from smooth daily variance? Bridge: B01.

Estimation basis: Editorial estimate for selected readings, scope navigation, one worked calculation, one transfer variant, practical work and remediation; 45–90 minutes per ordinary scope topic plus 2–8 practical hours, longer for specialist derivation. Projects budgeted separately. Not measured learner time.

Objectives:

- Construct a timestamped event calendar and precommit scenarios.
- Solve and explain: Total variance .04 annual times 30/365 equals .003288; a known hypothetical event variance .001 leaves .002288 diffusive variance.
- Audit the failure mode: Subtracting volatility rather than variance; ignoring after-hours announcements.

Mathematics: A, S (codes in MATH_ROADMAP). Programming: None for core explanations; optional Python for replication.

Reading: R01:X; R10:event chapters require licensed copy. Resource verification limits control use; a TOC assignment is a candidate, not a reviewed chapter. All learners can complete the synthetic numerical case without buying a book.

Ordered scope:

- M09.01 — Scheduled events: earnings, CPI, employment, central-bank meetings, settlement dates
- M09.02 — Unscheduled events: geopolitical shocks, litigation, accidents, emergency policy
- M09.03 — Earnings: release versus call, guidance, revisions, implied versus realized move
- M09.04 — Binary events: FDA decisions, court rulings, approvals, discrete outcome trees
- M09.05 — Mergers and acquisitions: deal terms, exchange ratios, financing, break risk, option adjustments
- M09.06 — Corporate distributions: ordinary/special dividends, spin-offs and altered deliverables
- M09.07 — Elections and policy: scenarios, timing uncertainty, changing correlations
- M09.08 — Product launches: expectation formation, delayed monetization, narrative risk
- M09.09 — Event calendars: timestamp provenance, rescheduling, before/after-market distinctions
- M09.10 — Conditional distributions: outcome probabilities, conditional spot and volatility responses
- M09.11 — Event overlap: separating macro, sector and company risk in one expiry
- M09.12 — Information discipline: primary filings, timestamps, embargoes, source verification

Teaching brief for module delivery: begin with the checkpoint dilemma, elicit the learner's units and obligations, work the numerical case, then use the practical assignment to challenge the main assumption. Ask for a counterexample before extending the scope. This is a module delivery plan, not a topic lesson.

Common mistakes:

- Subtracting volatility rather than variance; ignoring after-hours announcements.
- Accepting a result without its units, assumptions or source date.

Checkpoint questions:

- Why is an earnings gap different from smooth daily variance?
- Which assumption in your numerical result is most vulnerable, and what changes if it fails?

Mastery:

- Identify gaps, rescheduling, release-time uncertainty and conditional outcomes.
- At least 85% on quiz and rubric; no unresolved critical errors; solve a fresh transfer variant with reasoning.

Remediation: Diagnose the mistaken unit, model, observation or cash-flow step; revisit the cited entry bridge or source section, annotate the correction, then attempt an unseen variant after a separate review session.
