# M38 — Event volatility and short-dated optionality

Status: learning design; topic lessons remain P17. Slug: `event-volatility-and-short-dated-optionality`. Advanced; 24–48 hours. Tags: volatility, volatility-and-volatility-trading.

Separate event variance, expiry convexity and execution risk in earnings/0DTE hypotheses.

Hard prerequisites: C-M36, C-M22. Recommended preparation: C-M09, C-M35, C-M37. Optional enrichment: none. Diagnostic: Why does small remaining premium not mean small risk near expiry? Bridge: B02.

Estimation basis: Editorial estimate for selected readings, scope navigation, one worked calculation, one transfer variant, practical work and remediation; 45–90 minutes per ordinary scope topic plus 2–8 practical hours, longer for specialist derivation. Projects budgeted separately. Not measured learner time.

Objectives:

- Separate event variance, expiry convexity and execution risk in earnings/0DTE hypotheses.
- Solve and explain: One-day shock 5% at spot 100 is 5; a delta-only approximation near ATM expiry can miss the payoff kink.
- Audit the failure mode: Extrapolating ordinary-day fills or claiming universal dealer-gamma causality.

Mathematics: S, C, N (codes in MATH_ROADMAP). Programming: None for core explanations; optional Python for replication.

Reading: R32:sample-limited exchange study; R68:pp 29–30. Resource verification limits control use; a TOC assignment is a candidate, not a reviewed chapter. All learners can complete the synthetic numerical case without buying a book.

Ordered scope:

- M38.01 — Event variance extraction: expiry comparisons, baseline variance and discrete event contribution
- M38.02 — IV expansion: event proximity, annualization and changing total variance
- M38.03 — IV crush: removal of uncertainty versus spot move and remaining optionality
- M38.04 — Implied versus realized event move: sample selection, direction and asymmetry
- M38.05 — Binary payoff distributions: jumps, mixed outcomes and model inadequacy
- M38.06 — Event skew: asymmetric tails, crash/upside surprise and demand
- M38.07 — Event term structure: expiry straddling, multiple events and contaminated comparisons
- M38.08 — Intraday time conventions: remaining minutes, nontrading time and event clocks
- M38.09 — 0DTE risk: rapidly changing gamma, hedge frequency, liquidity and settlement
- M38.10 — Event trade selection: forecast distribution, executable cost and scenario outcomes
- M38.11 — Post-event management: stale quotes, liquidity normalization, exercise and new regime
- M38.12 — Event-study validation: announcement timestamps, pre-event information and matched controls
