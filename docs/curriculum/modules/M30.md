# M30 — Vanilla pricing models and exercise

Status: learning design; topic lessons remain P17. Slug: `vanilla-pricing-models-and-exercise`. Intermediate; 14–36 hours. Tags: options-pricing, pricing-greeks-and-hedging.

Implement and interpret BSM and binomial pricing, separating model price from edge.

Hard prerequisites: C-M29, C-M10. Recommended preparation: C-M13. Optional enrichment: none. Diagnostic: Why does N(d 2) still fail to give a real-world profit probability? Bridge: B02.

Estimation basis: Editorial estimate for selected readings, scope navigation, one worked calculation, one transfer variant, practical work and remediation; 45–90 minutes per ordinary scope topic plus 2–8 practical hours, longer for specialist derivation. Projects budgeted separately. Not measured learner time.

Objectives:

- Implement and interpret BSM and binomial pricing, separating model price from edge.
- Solve and explain: S100 K100 r.05 q 0 sigma.2 T1: call 10.45058357 put 5.57352602.
- Audit the failure mode: Using calendar days inconsistently or inferring future drift from risk-neutral pricing.

Mathematics: C, S, N (codes in MATH_ROADMAP). Programming: None for core explanations; optional Python for replication.

Reading: RX03:BSM assumptions; R05:13 and 15. Resource verification limits control use; a TOC assignment is a candidate, not a reviewed chapter. All learners can complete the synthetic numerical case without buying a book.

Ordered scope:

- M30.01 — Binomial models: CRR construction, risk-neutral probabilities and backward induction
- M30.02 — Trinomial trees: transition choices, convergence and early-exercise flexibility
- M30.03 — Black–Scholes–Merton: formula inputs, assumptions, replication intuition and derivation path
- M30.04 — BSM limitations: discrete hedging, jumps, smile, stochastic volatility, costs and borrow
- M30.05 — Dividend-adjusted equity pricing: yields, discrete cash dividends and model choices
- M30.06 — Black 76: forwards/futures options, discounting and underlying convention
- M30.07 — Bachelier pricing: normal volatility, nonpositive prices/rates and unit conventions
- M30.08 — Garman–Kohlhagen: FX domestic/foreign discounting and quotation conventions
- M30.09 — American exercise: continuation value versus intrinsic value, exercise boundaries
- M30.10 — American approximations: analytical approximations, tree/PDE comparison and errors
- M30.11 — Implied-volatility inversion: bounds, root finding, near-zero vega and no-solution cases
- M30.12 — Implied volatility is model-specific: lognormal/normal quotes and conversion limitations
- M30.13 — Digital option pricing: cash/asset-or-nothing, strike derivative and discontinuous hedging
- M30.14 — BSM PDE derivation: self-financing hedge, Ito lemma, boundary and terminal conditions

Teaching brief for module delivery: begin with the checkpoint dilemma, elicit the learner's units and obligations, work the numerical case, then use the practical assignment to challenge the main assumption. Ask for a counterexample before extending the scope. This is a module delivery plan, not a topic lesson.

Common mistakes:

- Using calendar days inconsistently or inferring future drift from risk-neutral pricing.
- Accepting a result without its units, assumptions or source date.

Checkpoint questions:

- Why does N(d 2) still fail to give a real-world profit probability?
- Which assumption in your numerical result is most vulnerable, and what changes if it fails?

Mastery:

- Explain convergence, early-exercise economics and when the selected model is unsuitable.
- At least 85% on quiz and rubric; no unresolved critical errors; solve a fresh transfer variant with reasoning.

Remediation: Diagnose the mistaken unit, model, observation or cash-flow step; revisit the cited entry bridge or source section, annotate the correction, then attempt an unseen variant after a separate review session.
