# M20 — Volatility, breadth, volume and order-flow indicators

Status: learning design; topic lessons remain P17. Slug: `volatility-breadth-volume-and-order-flow-indicators`. Intermediate; 19–46 hours. Tags: technical-analysis, price-behavior-and-technical-methods.

Separate traded volume, implied volatility, open interest and inferred flows.

Hard prerequisites: C-M04, C-M10. Recommended preparation: C-M15. Optional enrichment: none. Diagnostic: Why does open interest not reveal the dealer's signed position? Bridge: B01.

Estimation basis: Editorial estimate for selected readings, scope navigation, one worked calculation, one transfer variant, practical work and remediation; 45–90 minutes per ordinary scope topic plus 2–8 practical hours, longer for specialist derivation. Projects budgeted separately. Not measured learner time.

Objectives:

- Separate traded volume, implied volatility, open interest and inferred flows.
- Solve and explain: 100 new contracts create 100 open interest, not 200, although every contract has a long and short.
- Audit the failure mode: Adding trade volume into open interest; labeling all calls bullish.

Mathematics: A, S (codes in MATH_ROADMAP). Programming: None for core explanations; optional Python for replication.

Reading: R01:II; R32:exchange empirical discussion with sample limits. Resource verification limits control use; a TOC assignment is a candidate, not a reviewed chapter. All learners can complete the synthetic numerical case without buying a book.
