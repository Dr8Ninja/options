# M16 — Candlestick formations: a testable vocabulary

Status: learning design; topic lessons remain P17. Slug: `candlestick-formations-a-testable-vocabulary`. Intermediate; 20–48 hours. Tags: price-action, price-behavior-and-technical-methods.

Encode candle features with unambiguous timestamps and test incremental utility.

Hard prerequisites: C-M15. Recommended preparation: none. Optional enrichment: none. Diagnostic: Can the same candle imply the same option outcome at different IV? Bridge: B01.

Estimation basis: Editorial estimate for selected readings, scope navigation, one worked calculation, one transfer variant, practical work and remediation; 45–90 minutes per ordinary scope topic plus 2–8 practical hours, longer for specialist derivation. Projects budgeted separately. Not measured learner time.

Objectives:

- Encode candle features with unambiguous timestamps and test incremental utility.
- Solve and explain: Open 100 high 104 low 98 close 102: body 2, upper wick 2, lower wick 2.
- Audit the failure mode: Narrative certainty from candle names.

Mathematics: A, S (codes in MATH_ROADMAP). Programming: None for core explanations; optional Python for replication.

Reading: R28:reference only; R29:conditional distribution methods. Resource verification limits control use; a TOC assignment is a candidate, not a reviewed chapter. All learners can complete the synthetic numerical case without buying a book.

Teaching brief for module delivery: begin with the checkpoint dilemma, elicit the learner's units and obligations, work the numerical case, then use the practical assignment to challenge the main assumption. Ask for a counterexample before extending the scope. This is a module delivery plan, not a topic lesson.

Practice:

Reference: Use the module objective and stated failure mode; credit explicit conditions and a counterexample, not confidence.

**EX-M16-N** Compute, show units and assumptions; then change one input and justify the direction. Open 100 high 104 low 98 close 102: body 2, upper wick 2, lower wick 2.

Reference: Open 100 high 104 low 98 close 102: body 2, upper wick 2, lower wick 2.

**EX-M16-P** Label randomized candle examples before seeing subsequent prices.

Reference: State context, alternative outcomes and an objective rule for each studied formation.

Common mistakes:

- Narrative certainty from candle names.
- Accepting a result without its units, assumptions or source date.

Checkpoint questions:

- Can the same candle imply the same option outcome at different IV?
- Which assumption in your numerical result is most vulnerable, and what changes if it fails?

Mastery:

- State context, alternative outcomes and an objective rule for each studied formation.
- At least 85% on quiz and rubric; no unresolved critical errors; solve a fresh transfer variant with reasoning.

Remediation: Diagnose the mistaken unit, model, observation or cash-flow step; revisit the cited entry bridge or source section, annotate the correction, then attempt an unseen variant after a separate review session.
