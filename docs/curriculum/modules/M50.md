# M50 — Market microstructure and price discovery

Status: learning design; topic lessons remain P17. Slug: `market-microstructure-and-price-discovery`. Intermediate; 16–40 hours. Tags: microstructure, microstructure-execution-and-management.

Explain adverse selection, queue priority and price discovery using event sequences.

Hard prerequisites: C-M04, C-M10. Recommended preparation: none. Optional enrichment: none. Diagnostic: Why does a passive fill correlate with an unfavorable next price? Bridge: B01.

Estimation basis: Editorial estimate for selected readings, scope navigation, one worked calculation, one transfer variant, practical work and remediation; 45–90 minutes per ordinary scope topic plus 2–8 practical hours, longer for specialist derivation. Projects budgeted separately. Not measured learner time.

Objectives:

- Explain adverse selection, queue priority and price discovery using event sequences.
- Solve and explain: Buy at 100 then mid 99.8: adverse-selection markout -.2 before rebate; spread capture alone misleads.
- Audit the failure mode: Assuming price-time across all venues or observing hidden liquidity directly.

Mathematics: A, S (codes in MATH_ROADMAP). Programming: None for core explanations; optional Python for replication.
