# M33 — Higher-order Greeks and surface-sensitive risk

Hard prerequisites: C-M32, C-M13. Recommended preparation: none. Optional enrichment: none. Diagnostic: How does a sticky-strike vanna estimate differ from sticky-delta scenario P&L? Bridge: B02.

Estimation basis: Editorial estimate for selected readings, scope navigation, one worked calculation, one transfer variant, practical work and remediation; 45–90 minutes per ordinary scope topic plus 2–8 practical hours, longer for specialist derivation. Objectives:

- Define higher derivatives and surface conventions before aggregating them.
- Solve and explain: If vanna=.3 per spot per unit vol, dS2 and dvol.01 produce cross term .006 per share.
- Audit the failure mode: Treating vanna/charm dealer estimates as observed positions.
