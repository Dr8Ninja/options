# M12 — Time series, forecasting and regimes

Status: learning design; topic lessons remain P17. Slug: `time-series-forecasting-and-regimes`. Intermediate; 14–36 hours. Tags: quantitative, mathematics-and-inference.

Design forecasts respecting dependence, nonstationarity and evaluation time.

Hard prerequisites: C-M11. Recommended preparation: C-M10. Optional enrichment: none. Diagnostic: Why can random cross-validation leak adjacent financial observations? Bridge: B02.

Estimation basis: Editorial estimate for selected readings, scope navigation, one worked calculation, one transfer variant, practical work and remediation; 45–90 minutes per ordinary scope topic plus 2–8 practical hours, longer for specialist derivation. Projects budgeted separately. Not measured learner time.

Objectives:

- Design forecasts respecting dependence, nonstationarity and evaluation time.
- Solve and explain: AR(1) phi=.8, shock variance .36: stationary variance 1 if assumptions hold.
- Audit the failure mode: Forecasting returns and volatility as interchangeable; ignoring regime breaks.

Mathematics: S, L (codes in MATH_ROADMAP). Programming: None for core explanations; optional Python for replication.

Reading: R34:ARCH motivation; R25:time-series course sections. Resource verification limits control use; a TOC assignment is a candidate, not a reviewed chapter. All learners can complete the synthetic numerical case without buying a book.

Ordered scope:

- M12.01 — Time-series structure: trend, seasonality, cycles, noise and event time
- M12.02 — Stationarity: strict/weak forms, transformations, differencing and structural breaks
- M12.03 — Autocorrelation: ACF, PACF, returns versus squared returns
- M12.04 — Random walks: martingales, drift, efficient-market interpretations
- M12.05 — Mean reversion: half-life, persistence, unit-root testing and spurious regression
- M12.06 — AR, MA and ARIMA: specifications, forecast horizons, diagnostics
- M12.07 — ARCH and GARCH: volatility clustering, persistence, conditional variance
- M12.08 — Asymmetric variance models: GJR-GARCH, EGARCH and leverage effects
- M12.09 — HAR realized-volatility models: multiple horizons and long-memory approximations
- M12.10 — Cointegration: common trends, error correction and unstable pairs relationships
- M12.11 — State-space methods: Kalman filtering, latent state estimation, parameter uncertainty
- M12.12 — Regime models: Markov switching, change points, hidden states and overfitting
- M12.13 — Forecast evaluation: rolling origins, calibration, loss functions, benchmark comparisons
- M12.14 — Long memory and roughness: distinct meanings, estimation pitfalls and microstructure noise

Common mistakes:

- Forecasting returns and volatility as interchangeable; ignoring regime breaks.
- Accepting a result without its units, assumptions or source date.
