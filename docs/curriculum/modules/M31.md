# M31 — Numerical pricing and implementation quality

Status: learning design; topic lessons remain P17. Slug: `numerical-pricing-and-implementation-quality`. Intermediate; 13–34 hours. Tags: quantitative, pricing-greeks-and-hedging.

Compare Monte Carlo, trees and finite differences with convergence and error budgets.

Hard prerequisites: C-M30, C-M13, C-B03. Recommended preparation: C-M14. Optional enrichment: none. Diagnostic: Why does a tighter root tolerance not repair a biased discretization? Bridge: B03.

Estimation basis: Editorial estimate for selected readings, scope navigation, one worked calculation, one transfer variant, practical work and remediation; 45–90 minutes per ordinary scope topic plus 2–8 practical hours, longer for specialist derivation. Projects budgeted separately. Not measured learner time.

Objectives:

- Compare Monte Carlo, trees and finite differences with convergence and error budgets.
- Solve and explain: Independent Monte Carlo standard error scales 1/sqrt(N): quadrupling N halves sampling SE, not bias.
- Audit the failure mode: Negative tree probabilities; unstable grids; no confidence interval.

Mathematics: C, L, N, I (codes in MATH_ROADMAP). Programming: B03 plus arrays, functions and tests.

Reading: R33:documentation directory; R05:21; RX14:brentq documentation. Resource verification limits control use; a TOC assignment is a candidate, not a reviewed chapter. All learners can complete the synthetic numerical case without buying a book.

Ordered scope:

- M31.01 — Monte Carlo pricing: simulated paths, discounted payoffs, standard errors and confidence intervals
- M31.02 — Variance reduction: antithetic, control variates, importance sampling and stratification
- M31.03 — Quasi-Monte Carlo: low-discrepancy sequences, effective dimension and error assessment
- M31.04 — Finite differences: explicit/implicit schemes, Crank–Nicolson, stability and convergence
- M31.05 — Boundary handling: truncation, dividends, barriers, early exercise and grid refinement
- M31.06 — Least-squares Monte Carlo: American exercise regression, training/evaluation split and bias
- M31.07 — Fourier pricing: characteristic functions, FFT/COS methods and numerical integration
- M31.08 — Numerical Greeks: bump-and-revalue, bump choice, cancellation and noise
- M31.09 — Pathwise and likelihood-ratio Greeks: differentiability, discontinuities and variance
- M31.10 — Adjoint differentiation: efficient portfolio sensitivities and implementation validation
- M31.11 — Calibration objective: weights, bid/ask, regularization, constraints and identifiability
- M31.12 — Pricing quality tests: parity, monotonicity, limiting cases and benchmark convergence
- M31.13 — Model implementation risk: dates, day counts, units, dividend timing and calendars

Teaching brief for module delivery: begin with the checkpoint dilemma, elicit the learner's units and obligations, work the numerical case, then use the practical assignment to challenge the main assumption. Ask for a counterexample before extending the scope. This is a module delivery plan, not a topic lesson.

Common mistakes:

- Negative tree probabilities; unstable grids; no confidence interval.
- Accepting a result without its units, assumptions or source date.

Checkpoint questions:

- Why does a tighter root tolerance not repair a biased discretization?
- Which assumption in your numerical result is most vulnerable, and what changes if it fails?

- Reconcile results within justified tolerances and explain residual error.
