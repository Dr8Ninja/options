# M48 — Portfolio construction and option overlays

Status: learning design; topic lessons remain P17. Slug: `portfolio-construction-and-option-overlays`. Intermediate; 17–42 hours. Tags: portfolio-management, risk-and-portfolio-construction.

Aggregate factor, Greek and liquidity risks and compare hedge alternatives.

Hard prerequisites: C-M46, C-M32. Recommended preparation: C-M08, C-M45. Optional enrichment: none. Diagnostic: Why can many small short-vol positions create one concentrated bet? Bridge: B02.

Estimation basis: Editorial estimate for selected readings, scope navigation, one worked calculation, one transfer variant, practical work and remediation; 45–90 minutes per ordinary scope topic plus 2–8 practical hours, longer for specialist derivation. Projects budgeted separately. Not measured learner time.

Objectives:

- Aggregate factor, Greek and liquidity risks and compare hedge alternatives.
- Solve and explain: Two positions each delta 50 shares produce 100 shares aggregate, even with different strategy names.
- Audit the failure mode: Diversifying labels rather than exposures; ignoring cross-gamma.

Mathematics: S, L, C (codes in MATH_ROADMAP). Programming: None for core explanations; optional Python for replication.

Reading: R72:metadata only; R05:19/22. Resource verification limits control use; a TOC assignment is a candidate, not a reviewed chapter. All learners can complete the synthetic numerical case without buying a book.
