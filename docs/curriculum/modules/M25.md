# M25 — Vertical spreads and payoff algebra

Status: learning design; topic lessons remain P17. Slug: `vertical-spreads-and-payoff-algebra`. Beginner; 10–28 hours. Tags: options, option-contracts-and-structures.

Bound same-expiry vertical payoffs and model each assignment path.

Hard prerequisites: C-M24. Recommended preparation: none. Optional enrichment: none. Diagnostic: When can an operational cash need exceed the terminal spread loss? Bridge: B01.

Estimation basis: Editorial estimate for selected readings, scope navigation, one worked calculation, one transfer variant, practical work and remediation; 45–90 minutes per ordinary scope topic plus 2–8 practical hours, longer for specialist derivation. Projects budgeted separately. Not measured learner time.

Objectives:

- Bound same-expiry vertical payoffs and model each assignment path.
- Solve and explain: Buy 100 call 4 sell 105 call 2: debit 2, maxloss 2, maxprofit 3, break-even 102 per share.
- Audit the failure mode: Applying terminal bounds to intraday funding obligations.

Mathematics: A (codes in MATH_ROADMAP). Programming: None for core explanations; optional Python for replication.

Reading: R01:X spread risks; RX02:synthetics. Resource verification limits control use; a TOC assignment is a candidate, not a reviewed chapter. All learners can complete the synthetic numerical case without buying a book.

Ordered scope:

- M25.01 — Bull call spread: debit, upside cap, long/short strikes and expiry payoff
- M25.02 — Bear call spread: credit, upside loss region and collateral
- M25.03 — Bull put spread: credit, downside loss region and assignment
- M25.04 — Bear put spread: debit, downside cap and exercise considerations
- M25.05 — Debit and credit equivalence: financing, same terminal payoff and quote differences
- M25.06 — Spread width and strike placement: capital, payoff density and tail exposure
- M25.07 — Vertical Greeks: net delta/gamma/vega/theta vary with spot, time and strikes
- M25.08 — Spread breakeven: expiry definition versus pre-expiry liquidation outcome
- M25.09 — Defined terminal risk: fees, legging, early assignment and residual-position caveats
- M25.10 — Vertical selection: risk/reward, implied distribution, skew and executable prices

Teaching brief for module delivery: begin with the checkpoint dilemma, elicit the learner's units and obligations, work the numerical case, then use the practical assignment to challenge the main assumption. Ask for a counterexample before extending the scope. This is a module delivery plan, not a topic lesson.

Practice:

**EX-M25-C** When can an operational cash need exceed the terminal spread loss?

Reference: Use the module objective and stated failure mode; credit explicit conditions and a counterexample, not confidence.

**EX-M25-N** Compute, show units and assumptions; then change one input and justify the direction. Buy 100 call 4 sell 105 call 2: debit 2, maxloss 2, maxprofit 3, break-even 102 per share.

Reference: Buy 100 call 4 sell 105 call 2: debit 2, maxloss 2, maxprofit 3, break-even 102 per share.

**EX-M25-P** Derive all four verticals and reconcile equivalent debit/credit terminal payoffs.

Reference: Calculate bounds and explain how expiry operations can create additional exposure.

Common mistakes:

- Applying terminal bounds to intraday funding obligations.
- Accepting a result without its units, assumptions or source date.

Checkpoint questions:

- When can an operational cash need exceed the terminal spread loss?
- Which assumption in your numerical result is most vulnerable, and what changes if it fails?

Mastery:

- Calculate bounds and explain how expiry operations can create additional exposure.
- At least 85% on quiz and rubric; no unresolved critical errors; solve a fresh transfer variant with reasoning.

Remediation: Diagnose the mistaken unit, model, observation or cash-flow step; revisit the cited entry bridge or source section, annotate the correction, then attempt an unseen variant after a separate review session.
