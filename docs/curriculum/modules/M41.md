# M41 — Professional volatility and relative-value trading

Status: learning design; topic lessons remain P17. Slug: `professional-volatility-and-relative-value-trading`. Advanced; 34–63 hours. Tags: volatility, volatility-and-volatility-trading.

Measure relative-value, skew, term and dispersion exposure with realistic hedge/correlation risks.

Hard prerequisites: C-M37, C-M34, C-M08. Recommended preparation: C-M28, C-M38. Optional enrichment: none. Diagnostic: Why does index variance differ from average constituent variance? Bridge: B02.

Estimation basis: Editorial estimate for selected readings, scope navigation, one worked calculation, one transfer variant, practical work and remediation; 45–90 minutes per ordinary scope topic plus 2–8 practical hours, longer for specialist derivation. Projects budgeted separately. Not measured learner time.

Objectives:

- Measure relative-value, skew, term and dispersion exposure with realistic hedge/correlation risks.
- Solve and explain: Two equal-weight 20% constituents withrho.5: indexvariance .03 andvol 17.3205%.
- Audit the failure mode: Ignoring constituent weights, jumps, rebalancing and index/stock settlement differences.

Mathematics: S, L, C, N (codes in MATH_ROADMAP). Programming: None for core explanations; optional Python for replication.

Reading: R12:variance replication; RX10:correlation chapter. Resource verification limits control use; a TOC assignment is a candidate, not a reviewed chapter. All learners can complete the synthetic numerical case without buying a book.
