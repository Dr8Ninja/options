# M17 — Chart patterns and competing interpretations

Status: learning design; topic lessons remain P17. Slug: `chart-patterns-and-competing-interpretations`. Intermediate; 20–48 hours. Tags: technical-analysis, price-behavior-and-technical-methods.

Define patterns algorithmically and test them against simple baselines.

Hard prerequisites: C-M15. Recommended preparation: none. Optional enrichment: none. Diagnostic: How would two blinded annotators disagree on this pattern? Bridge: B01.

Estimation basis: Editorial estimate for selected readings, scope navigation, one worked calculation, one transfer variant, practical work and remediation; 45–90 minutes per ordinary scope topic plus 2–8 practical hours, longer for specialist derivation. Projects budgeted separately. Not measured learner time.

Objectives:

- Define patterns algorithmically and test them against simple baselines.
- Solve and explain: A 10-point measured-move claim with 6-point realized move has error -4; evaluate all signals, not winners.
- Audit the failure mode: Selecting clean historical examples and omitting failed patterns.

Mathematics: S (codes in MATH_ROADMAP). Programming: None for core explanations; optional Python for replication.

Reading: R29:pattern-recognition method. Resource verification limits control use; a TOC assignment is a candidate, not a reviewed chapter. All learners can complete the synthetic numerical case without buying a book.

Teaching brief for module delivery: begin with the checkpoint dilemma, elicit the learner's units and obligations, work the numerical case, then use the practical assignment to challenge the main assumption. Ask for a counterexample before extending the scope. This is a module delivery plan, not a topic lesson.

Practice:

**EX-M17-C** How would two blinded annotators disagree on this pattern?

Reference: Use the module objective and stated failure mode; credit explicit conditions and a counterexample, not confidence.

**EX-M17-N** Compute, show units and assumptions; then change one input and justify the direction. A 10-point measured-move claim with 6-point realized move has error -4; evaluate all signals, not winners.

Reference: A 10-point measured-move claim with 6-point realized move has error -4; evaluate all signals, not winners.

**EX-M17-P** Operationalize one chart pattern and compare outcomes with matched non-pattern controls.

Reference: Report failures and base rates; do not select examples only after favorable outcomes.

Common mistakes:

- Selecting clean historical examples and omitting failed patterns.
- Accepting a result without its units, assumptions or source date.

Checkpoint questions:

- How would two blinded annotators disagree on this pattern?
- Which assumption in your numerical result is most vulnerable, and what changes if it fails?

Mastery:

- Report failures and base rates; do not select examples only after favorable outcomes.
- At least 85% on quiz and rubric; no unresolved critical errors; solve a fresh transfer variant with reasoning.

Remediation: Diagnose the mistaken unit, model, observation or cash-flow step; revisit the cited entry bridge or source section, annotate the correction, then attempt an unseen variant after a separate review session.
