# Book, lecture and practitioner-resource evaluations

These evaluations distinguish bibliographic/contents inspection from reading the book. None of the paywalled books was reviewed in full. Assignments below are selected candidates; chapters requiring a purchased/library copy remain optional or reference until access is available. A free alternative covers the named competency, not necessarily the entire book.

Original lectures: MIT Finance Theory I provides slides and lecture/transcript access; slides 3–13 and 16–21 were selected for payoff and replication work, with the image-only PDE on slide 21 visually checked. Video segments were not watched, so no timestamps are fabricated. Engle’s Nobel lecture is an original lecture PDF, useful for the motivation of conditional volatility; it does not validate a trading strategy. MIT calculus/probability courses provide worked problems/exams, but exact exercise-number assignments require P17 selection and access checks.

Broker education: Zerodha Varsity’s Options Theory directory is a candidate for an India-friendly explanation route. It is not an authority for permanent current lots, fees or expiry rules. OCC/OIC, Cboe and CME education are useful, but educational shortcuts are checked against mathematics: for example, delta as an approximate ITM probability cannot replace the distinction between N(d1), N(d2), physical probabilities and probability of net profit.

Tools: Python, NumPy, pandas, SciPy, statsmodels, matplotlib, QuantLib and optional scikit-learn have roles tied to specific projects in PROGRAMMING_ROADMAP. Moving documentation URLs are not a tested environment. yfinance is evaluated separately for code licensing and data entitlement. No project is called maintained solely because it is hosted on GitHub; release/activity and security/version checks must accompany the implementation-stage pin.
