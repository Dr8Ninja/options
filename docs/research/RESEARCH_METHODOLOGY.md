# P01 research methodology

Question: what must a learner be able to explain, calculate, test and operate safely to understand options from entry level through professional specializations, and which supplied claims/resources actually support that learning?

Entry audit reused the existing extraction only after `python3 scripts/inventory_sources.py --check` passed. All three original roadmap representations, both archived follow-up prompts, the master brief/shared instructions, inventory artifacts including supplemental.json, G01–G25 and Q001–Q029 were read. Equivalent catalog/Markdown text was read through the losslessly checked inventory instead of treating identical copies as independent evidence. Originals and hashes remain unchanged. The latest user instruction removes any real-money requirement and excludes application design/implementation from P01.

Selection order is task-sensitive: operative exchange/clearing/regulator notice and its amendment chain for rules; primary papers and authoritative textbooks for conditional theory; full methods/results for empirical findings; official university lectures and library documentation for teaching/numerics; well-evidenced practitioner material for implementation context. Broker education may explain but cannot override operative rules. Academic journals and primary preprints are distinguished. arXiv is a repository, not proof of peer review; SSRN discovery would receive the same treatment. No minimum link count substitutes for resolving the question.

Exclude promotional performance claims, copied unattributed summaries, search snippets as final evidence, inaccessible abstracts as if full methods were read, unlicensed book mirrors, stale investor decks as current specifications, and fame as validation. Source authority is necessary in some domains but not sufficient: R56 contains a numeric inconsistency and R58 has conflicting tax-base wording. Preserve these disagreements and their exact scope.

Workflow: frame a falsifiable question → inspect existing scope and gaps → prioritize safety/currency/dependency risks → search authoritative sources → retrieve lawful sections → record section/page, access, date and limitations → separate claim class → design an assessment that could reveal misunderstanding → review the resulting canonical material. For PDFs with formulas/tables, inspect rendered pages where extraction may mislead. R56’s disputed table and MIT’s image-only formula were visually checked. Downloaded third-party files remained temporary outside the distributable data directory.

Evidence levels are explicit: discovery; transport/access; bibliographic/TOC review; selected-content review; claim verification under conditions; independent numerical/empirical replication. HTTP200 only establishes retrieval. A failed route may be retried through an official attachment, author copy or university repository; access failure never licenses use of an unauthorized copy. Exact inaccessible sections remain excluded or optional with alternatives.

The reproducible log consists of [search-log-p01.json](../../research/search-log-p01.json), canonical URLs/sections in the [claim register](../../research/registers/claims.json), per-request access reports with timestamps/hashes, and the preserved initial evidence ledger plus P01 updates. Some raw web calls contain session-local result IDs; canonical URLs and read scopes in the ledger/resource records are the durable replay targets. Re-run searches with the same words/domain filters, then inspect the named source/version; changed results are a new observation, not a rewrite of history.

Prioritization: P0 contract/cash/assignment, source conflicts, rights/leakage, units and dependencies; P1 volatility/surfaces, numerical methods, professional operations and cases; P2 specialist refinements and publication authoring. [questions.json](../../research/registers/questions.json) records domain-specific stopping decisions. Diminishing returns means another broad source is unlikely to change the curriculum decision; unresolved exact rule chains, inaccessible advanced chapters or unfinished teaching remain named work. It does not mean research uncertainty has disappeared.

Reproducibility has limits: live pages and search rankings change; not all resources expose a publication date; paid chapters were not reviewed in full; no licensed options dataset was purchased; no empirical strategy result was independently replicated. Numerical teaching references are checked separately from literature review. P17 must review and test each actual lesson before publication. The three P01 passes are one agent applying 12 professional/learner lenses, not independent expert endorsement.
