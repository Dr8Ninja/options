## What exists

Java 25/Spring Boot 4.1.1 executable modular monolith; PostgreSQL 18.6 JDBC sessions with a Flyway-owned schema; validation/deny-by-default Spring Security and CSRF/origin defenses; separate minimal health/readiness; sanitized structured request logs and server-generated UUID references; Next 16.3.6/React 19.3.0 dynamic shell with P06 light/dark tokens, metadata/noindex, CSP, safe error boundaries and typed same-origin browser/fixed-origin SSR adapters. Infrastructure supplies a local HTTPS proxy, database/mail sink and app containers. Maven Wrapper, npm lockfile, CI and test harnesses are real executable configuration.

The shell states preparation honestly. It has no lesson content, catalog fixtures, learner counters, fake accounts, scoring, editorial tools or links to unfinished feature routes. The entire reviewed OpenAPI generates compile-time types, but only `getCsrf` is implemented; `/api/health` is a separate infrastructure route. The generated runtime spec is checked against that implemented subset, not equated with the entire P05 contract.

## Failures and repairs retained

1. Initial `java -version` failed; PATH held Node 26 and no Docker CLI. Installed verified local tools without changing system Java/Node. Docker Desktop first returned no socket, then a transient 500 and stalled starts; after the daemon recovered, actual Testcontainers and full-container tests passed. The Mac was locked during an attempted UI inspection; no UI security prompt was bypassed. A later explicit continuation allowed finishing verification.
2. Port 5432 was already owned by an unrelated service. Kept it intact and bound the project's DB to loopback 55432. Compose's first attempt failed visibly before the port correction. A direct bind-mounted Caddy config was replaced with an image COPY; fresh setup no longer depends on sharing the project directory with Docker.
3. npm rejected TypeScript 7.0.2 against the selected generator's 5.x peer contract. An ESLint 10/composite-Next-config trial also found incompatible React lint peers; the temporary ESLint 9 alternative was rejected as unsupported. Final: TypeScript 5.9.3, ESLint 10.11.0 with compatible TypeScript, Next and Hooks plugins; strict peer checking and clean lockfile install. No forced resolution or blanket override.
4. Trivy found three critical Tomcat 11.0.24 advisories. Updated only Tomcat to 11.0.26 after Apache source review, rebuilt and rescanned; no CVE suppression. [ADR-007](../../adr/007-foundation-compatibility.md) records the exception. macOS JDK and published Linux JRE patch strings differ and are recorded separately.
5. Integration construction initially needed Testcontainers' compatible image declaration for digest references. A migration assertion initially counted Flyway's schema-creation marker as a SQL migration; corrected the assertion to count successful SQL entries and kept the rollback assertion. Missing resource errors now return safe 404s.
6. The WebAuthn fixture initially used the customized form-page URL as its implicit login processing path; made `/login` explicit. A virtual authenticator lacking user verification was initially rejected by the browser before reaching Spring; CDP's bad-UV response mode exercises the server-side negative case. The both-factor test exposed the need for Spring's explicit MFA aggregation enablement; enabled framework MFA support without permitting any production route. A generated-spec check caught the nested test controller being discovered in the ordinary integration context; conditioned the test-only controller on an explicit fixture property. Both the contract subset check and real WebAuthn probe then passed.
7. Gitleaks flagged three documented UUID idempotency examples, four file digests and two preserved ISBN descriptions. Inspected the exact source lines, preserved all original bytes and added exact-line fingerprints with comments; no real credential was suppressed.

8. The final fresh-setup audit caught a missing scanner checksum manifest. Added the four official release pins, reran the macOS installer, independently verified the Linux archive hashes and added manifest completeness to the dependency-policy gate. Shutdown and restart of the full stack also passed.
