# P03 official-source review and search record

Research began 22 September and was completed/rechecked 23 September 2026, Asia/Kolkata. This record supports technology decisions, not financial claims. Only primary maintainer/vendor material was adopted. Search snippets, forum posts and third-party version summaries were excluded as authority. Read scope below is intentionally bounded; no complete documentation set, package source code or deployed service was audited.

The [retrieval register](source-retrievals.json) records URLs, retrieval date, status, page hashes and selected package-publisher metadata. Hashes fingerprint mutable pages; they do not freeze support commitments. The [ADRs](../ARCHITECTURE.md) link claims at their point of use. Direct HTTP failures do not erase successfully read web-tool sections, and a 200 response is not integration proof.

## Access and evidence limitations

Render's web-text extraction omitted compute price tables; direct public HTML text included the tables and was inspected. Resend's relevant transactional prices appeared late in the extracted page; the unrelated $20 domain add-on was not used. DigitalOcean PostgreSQL numbers differ from its Valkey prices; the PostgreSQL-specific table is the cited comparison. Some direct Python requests to DigitalOcean/Backblaze returned 403 while official web-tool pages were readable. Backblaze was explored but not selected or used in the cost calculation.

The obsolete Redgate `/fd/...` PostgreSQL URL and a guessed Render version-policy URL failed; maintained official replacement pages were used. A Next self-hosting direct fetch once reset; web-tool access succeeded. The initial HTML parsing helper assumed BeautifulSoup was installed; it was not, so a standard-library HTMLParser was used without installing packages. No extraction failure is represented as a full review. Dynamic retrieval hashes may change without a product-version change.

Prices/support tables can change before the lengthy authoring phase ends. P07 rechecks versions; P21/P22 recheck provider features, exact regional calculator, retention and billing before any purchase. P03's documentary compatibility establishes a coherent supported design, not tested binaries, security assurance, load capacity, processor approval or a launch date.
